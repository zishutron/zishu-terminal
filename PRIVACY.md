# Privacy

Zishu Terminal does not include analytics, advertising or crash-reporting
libraries, and the app does not send your commands, files or personal data to
the developer.

Network access is used only for things you start:

- `zbootstrap install` downloads the Linux userspace from this project's
  GitHub Releases (github.com).
- `pkg` downloads packages from this project's apt repository on GitHub Pages
  (zishutron.github.io).
- Programs you run yourself (curl, git, pip, npm, ssh ...) connect wherever
  you tell them to.

GitHub and other servers you connect to may log your IP address under their
own privacy policies.

Everything you create (files, history, settings) stays in the app's private
storage on your device unless you copy or back it up yourself.

Permissions: INTERNET (downloads), READ/WRITE_EXTERNAL_STORAGE (file access,
write only up to Android 9), WAKE_LOCK (keeps long tasks running).

Contact: https://github.com/zishutron/zishu-terminal/issues
